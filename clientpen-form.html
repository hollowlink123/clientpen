Webhook passphrase (optional)
A shared secret checked inside your n8n workflow, not a header

This value is sent as a normal field inside the form submission (not an HTTP header), so it works reliably from a plain browser page. Add an IF node right after your Webhook node in n8n that checks the incoming passphrase field matches this value before continuing.

Privacy note: Your webhook URLs and passphrase are stored only in this browser's localStorage (never sent anywhere except to your own n8n instance). If you share this computer or the HTML file, clear your profile first. No data is ever sent to Clientpen servers — this is a 100% frontend, self-hosted tool.
